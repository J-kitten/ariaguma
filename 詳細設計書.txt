## Rails

### URL

POST /google_login

---

### Controller

GoogleAuthController

処理内容

1. Firebase Token受信
2. Token検証
3. User検索
4. Session作成
5. JSON返却

---

### Session保存項目

session[:user_id]

session[:email_hash]

---

### Response

成功

{
"success": true,
"user": {
"id": 2,
"email": "[sample@example.com](mailto:sample@example.com)"
}
}

失敗

{
"success": false,
"error": "Authentication failed"
}

| encrypted_password | string   |
| created_at         | datetime |
